# Project9 v0.4a

The shared console now exposes terminal attributes and a viewport size.
Run `stty -a` to see the current settings. `stty sane` restores the
default flags and control characters. Start a new `man` session after
changing the size to use the new rows and columns.

The viewport starts at 80 by 24 for the serial console. On the Gallant
framebuffer you can use all 32 rows and 85 columns with
`stty rows 32 columns 85`. That setting affects serial programs too.
Restore `stty rows 24 columns 80` for a typical serial terminal.

Programs can call `tcgetattr`, `tcsetattr`, `cfmakeraw` and `isatty`.
The `ioctl` requests are documented in the guest as `man 2 ioctl`
and `man 2 termios`. This release implements input modes with
`VMIN=1` and `VTIME=0`. Terminal attributes belong to the shared
console. Login restores canonical defaults and reads passwords with
echo disabled. The pager uses a temporary input mode that follows
foreground job control.

## Update an existing disk

See the [ext2 migration guide](../ext2.md#migrate-a-previous-installation)
for the current release.

The v0.4a updater saves the original as `fs.pre-v04a.img`. It updates the
system programs and manual pages on the copy, preserving accounts and
files. Older disks may still have the archived diagnostic executables
under `/bin`.

## Check the terminal

Run `ttytest` from the console. Try `stty -echo`, then type `stty sane`
and press Enter to restore echo. Try `stty rows 12 columns 60` followed
by `man man`. The pager should display 11 lines per screen. Restore the
default dimensions with `stty rows 24 columns 80`.
